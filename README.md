
# GMMPS v1.5.1 and ESO SkyCat

    Thsi repository contains a port of the Gemini MOS Mask Preparation
Software (GMMPS) used to design multi-object spectroscopy masks for GMOS
and Flamingos instruments. GMMPS uses the ESO SkyCat tool for visualization.

This software is a port of the GMMPS v1.5.1 and dependendent libraries to
work with Apple Silicon and modern MacOS systems.  It is provided as-is with
no support promised.
